## Conclusion générale

Les affiches peuvent être différenciées grâce à plusieurs familles de caractéristiques, 
mais aucune caractéristique ne suffit seule. Le modèle doit apprendre des combinaisons de 
signaux :

```text
couleur + luminosité + texture + contours + composition
```

Par exemple :

```text
affiche sombre
+ faible colorfulness
+ forte proportion de pixels sombres
+ texture homogène
= probablement horreur
```

Ou :

```text
affiche claire
+ colorfulness élevée
+ saturation élevée
+ contours nombreux
= probablement animation ou comédie
```

## 1. Différences observées entre les genres

### Horreur

Les affiches d’horreur sont généralement :

- les plus sombres ;
- moins colorées ;
- caractérisées par une forte proportion de pixels sombres ;
- moins lumineuses dans les quatre zones de l’affiche ;
- associées à une luminosité LAB `L` plus faible.

Valeurs observées :

```text
brightness_mean ≈ 95
dark_ratio      ≈ 0.55
colorfulness    ≈ 43
```

Le modèle peut donc utiliser la combinaison :

```text
brightness_mean faible
+ dark_ratio élevé
+ colorfulness faible
+ value_hist_0 élevé
```

### Blockbuster

Les blockbusters sont également plutôt sombres, mais ils sont difficiles à distinguer des films d’horreur avec les seules couleurs.

Valeurs observées :

```text
brightness_mean ≈ 112
dark_ratio      ≈ 0.46
colorfulness    ≈ 50
```

La classe `blockbuster` est aussi sous-représentée avec seulement `169` images. 
Le modèle apprend donc moins bien cette catégorie.

Pour mieux la distinguer, les caractéristiques les plus intéressantes sont :

- la composition ;
- les contours ;
- les formes ;
- la luminosité par zone ;
- les histogrammes HOG ;
- les caractéristiques de couleur LAB.

### Animation

Les affiches d’animation sont globalement :

- lumineuses ;
- colorées ;
- relativement saturées ;
- riches en contrastes et en contours.

Valeurs observées :

```text
brightness_mean ≈ 157
dark_ratio      ≈ 0.25
colorfulness    ≈ 68
```

La combinaison suivante est intéressante :

```text
brightness_mean élevé
+ dark_ratio faible
+ colorfulness élevé
+ saturation élevée
```

### Comédie

Les affiches de comédie sont également lumineuses, mais leur colorfulness moyenne est 
légèrement inférieure à celle de l’animation.

Valeurs observées :

```text
brightness_mean ≈ 159
dark_ratio      ≈ 0.25
colorfulness    ≈ 65
```

La différence entre animation et comédie est donc difficile à établir uniquement avec les 
statistiques globales. Les informations de forme et de composition sont importantes.

### Art et essai

Les affiches d’art et essai sont souvent :

- plus grandes ;
- légèrement plus verticales ;
- moins colorées que l’animation et la comédie ;
- plus lumineuses que l’horreur ;
- relativement homogènes selon les zones.

Valeurs observées :

```text
brightness_mean ≈ 140
dark_ratio      ≈ 0.31
colorfulness    ≈ 54
aspect_ratio    ≈ 0.73
```

Il faut être prudent avec `aspect_ratio`, car le modèle peut apprendre le format 
de collecte plutôt que le genre réel.

### Histogrammes

Les histogrammes donnent une information plus détaillée qu’une simple moyenne.

À utiliser :

```text

saturation_hist_0 ... saturation_hist_15

```

Par exemple, `value_hist_0` indique la proportion de pixels très sombres. Cette caractéristique a obtenu un score élevé dans ton analyse.

Les histogrammes permettent de distinguer :

- une image globalement sombre ;
- une image contenant simultanément des zones très claires et très sombres ;
- une image dominée par certaines couleurs ;
- une image peu saturée ou très colorée.

## 3. Composition spatiale

La composition consiste à ne pas analyser l’affiche uniquement comme une moyenne globale. On la découpe en quatre zones :

```text
+----------------+----------------+
| haut-gauche    | haut-droite    |
+----------------+----------------+
| bas-gauche     | bas-droite     |
+----------------+----------------+
```

Pour chaque zone, on calcule :

```text
brightness
saturation
colorfulness
edge_density
```

Cela permet au modèle de différencier des affiches ayant la même moyenne globale mais une organisation différente.

Par exemple :

```text
fond clair en haut + personnages sombres en bas
```

est différent de :

```text
personnage clair au centre + fond sombre partout ailleurs
```

Les caractéristiques par zone obtenues dans ton analyse sont très intéressantes. Par exemple :

```text
zone_0_1_brightness
zone_1_1_brightness
zone_0_0_brightness
zone_1_0_brightness
```

ont des scores ANOVA élevés.

## 6. Modèle conseillé

Pour ton cas, le modèle final devrait être :

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import LinearSVC

model = make_pipeline(
    StandardScaler(),
    LinearSVC(
        class_weight="balanced",
        max_iter=3000,
        random_state=42
    )
)
```

Pourquoi le SVM linéaire ?

- il fonctionne bien avec des caractéristiques numériques ;
- il nécessite une standardisation ;
- il supporte `class_weight="balanced"` ;
- il est plus simple à interpréter ;
- il évite parfois le surapprentissage d’Extra Trees sur des caractéristiques fortement corrélées.

Dans tes résultats :

```text
SVM linéaire + features visuelles enrichies
Accuracy : 0.53
Macro-F1 : 0.49
```

Ce score est plus honnête que le score avec dimensions, car il repose sur des 
caractéristiques visuelles plutôt que sur le format des fichiers.

## 7. Évaluation correcte

Il faut conserver :

```python
X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.2,
    stratify=y,
    random_state=42
)
```

Puis mesurer :

```python
from sklearn.metrics import classification_report, confusion_matrix

predictions = model.predict(X_test)

print(classification_report(
    y_test,
    predictions,
    target_names=[
        "animation",
        "blockbuster",
        "horreur",
        "comédie",
        "art_et_essai",
    ],
    zero_division=0,
))

print(confusion_matrix(y_test, predictions))
```

Il faut principalement regarder :

- le `macro-F1` ;
- le F1-score de `blockbuster` ;
- les confusions entre `horreur` et `blockbuster` ;
- les confusions entre `animation` et `comédie` ;
- les confusions entre `comédie` et `art_et_essai`.

L’accuracy seule est insuffisante, car `art_et_essai` possède beaucoup plus d’exemples 
que `blockbuster`.

## 8. Ce qu’il faudrait améliorer ensuite

La principale faiblesse est le déséquilibre des classes :

```text
blockbuster   : 169
art_et_essai  : 1160
```

Pour améliorer le modèle :

1. conserver `class_weight="balanced"` ;
2. utiliser `stratify=y` ;
3. faire une validation croisée stratifiée ;
4. augmenter uniquement la classe `blockbuster` si c’est autorisé ;
5. supprimer les caractéristiques constantes ;
6. tester plusieurs valeurs de régularisation du SVM ;
7. ne pas utiliser les dimensions dans le modèle final ;
8. comparer les résultats avec les mêmes partitions train/test.

La stratégie la plus défendable est :

```text

3. Texture :
   GLCM + LBP

4. Forme :

   mêmes mesures calculées dans quatre zones

7. Modèle :

8. Évaluation :
   macro-F1 + F1 par classe + matrice de confusion
```

Les résultats montrent que les genres les plus faciles à différencier sont probablement
 `horreur` et les genres lumineux comme `animation` ou `comédie`. Les difficultés principales

   `animation`, `comédie` et `art_et_essai`, qui nécessitera surtout les informations de
    forme et de composition.
